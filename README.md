# Python Conditional Statement Practice

## About

This repository contains Python programs I developed to practice conditional statements and improve my problem-solving skills.

## Topics Covered

* If, elif, and else statements
* Nested conditional statements
* Even or odd number checking
* Positive and negative number checking
* ASCII values and character checking
* Vowel checking
* Finding the middle value
* Checking palindrome numbers
* Identifying the quadrant of a point
* Comparing values using conditional logic

## Technologies Used

* Python 3
* PyCharm

2. Open the project in PyCharm or VS Code.
3. Run any Python file.
4. Enter the required input when prompted.
